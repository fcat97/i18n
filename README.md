# 🌐 i18n

> Universal localization solution for all platforms

Manage your app translations in **one place**, generate files for **any platform**.

## Platforms

| Platform | Status | Branch |
|----------|--------|--------|
| Android (Gradle) | ✅ Available | [`android-gradle`](https://github.com/fcat97/i18n/tree/android-gradle) |
| Flutter (Dart) | 🔜 Coming Soon | `dart` |
| iOS (Swift) | 🔜 Coming Soon | `ios` |
| React Native | 🔜 Coming Soon | `react` |

## How It Works

```
Google Sheets → [Generate] → Platform Strings
```

One spreadsheet → All your platform files

---

### Why Use This Plugin? 

Single Source of Truth - Edit translations in Google 
Sheets, not code Automatic Sync - Run one command to fetch and generate all 
strings Multi-language Support - Add as many languages as you need Developer 
Friendly - No manual copy-pasting of string files
