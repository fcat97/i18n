> iOS localization, driven by Google Sheets. Part of the [i18n](https://github.com/fcat97/i18n) family.

Manage your app translations in a **single Google Sheet** and generate iOS localization files with one command.

## Platforms

| Platform | Branch |
|----------|--------|
| **iOS (Swift SPM)** — this branch | [`ios`](https://github.com/fcat97/i18n/tree/ios) |
| Android (Gradle) | [`android-gradle`](https://github.com/fcat97/i18n/tree/android-gradle) |

## Why Use This?

- **Single Source of Truth** — Edit translations in Google Sheets, not code
- **Two Output Formats** — Classic `.strings` or modern `.xcstrings` (String Catalogs)
- **Automatic Sync** — One command fetches and generates all string files
- **Native Integration** — Swift Package Manager plugin, works with Xcode

## Quick Start

### 1. Add the Package

In your Xcode project or `Package.swift`:

```swift
.package(url: "https://github.com/fcat97/i18n", branch: "ios")
```

> No target dependency needed — the plugin is used as a command, not a library.

### 2. Set Up Your Google Sheet

Format your sheet like this:

| key | platform | default | en | my | zh |
|-----|----------|---------|----|----|----|
| app_name | ios | My App | My App | မြန်မာပါတ် | 我的应用 |
| welcome | ios | Welcome | Welcome | မင်္ဂလာပါ | 欢迎 |
| shared | android,ios | Shared | Shared | မြန်မာ | 共享 |

Make the sheet public: **File → Share → Publish to web → CSV**.

### 3. Create `i18n.json`

Place this in your project root (next to `Package.swift` or anywhere in the project tree):

```json
{
  "url": "https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit",
  "outputDir": "MyApp/Resources",
  "format": "strings"
}
```

### 4. Run the Plugin

```bash
swift package plugin generate-ios-i18n
```

That's it! Your localization files are generated automatically.

## Output Formats

### `"format": "strings"` (Default — all iOS versions)

Generates classic per-locale `.strings` files:

```
MyApp/Resources/
  Base.lproj/
    Localizable.strings     ← default locale values
  en.lproj/
    Localizable.strings
  my.lproj/
    Localizable.strings
  zh.lproj/
    Localizable.strings
```

Each file:
```
/* Auto-generated by i18n plugin. Do not edit manually. */
"app_name" = "My App";
"welcome" = "Welcome";
```

### `"format": "xcstrings"` (Xcode 15+ / iOS 17+)

Generates a single modern String Catalog file:

```
MyApp/Resources/
  Localizable.xcstrings     ← one JSON file with all locales
```

Xcode displays `.xcstrings` files in the String Catalog editor. Structure:
```json
{
  "version": "1.0",
  "strings": {
    "app_name": {
      "localizations": {
        "en": { "stringUnit": { "value": "My App", "state": "translated" } },
        "my": { "stringUnit": { "value": "မြန်မာပါတ်", "state": "translated" } }
      }
    }
  }
}
```

## Configuration Options

| Key | Required | Default | Description |
|-----|----------|---------|-------------|
| `url` | ✅ | — | Google Sheet URL |
| `outputDir` | ✅ | — | Output directory (relative to `i18n.json`) |
| `format` | ❌ | `"strings"` | `"strings"` or `"xcstrings"` |

## Xcode Build Phase Integration (Optional)

To auto-generate strings on every build, add a **Run Script** phase in Xcode:

1. Select your target → **Build Phases** → **+** → **New Run Script Phase**
2. Move it **before** the Compile Sources phase
3. Add:

```bash
cd "$SRCROOT"
swift package plugin generate-ios-i18n
```

## Spreadsheet Format

| Column | Required | Description |
|--------|----------|-------------|
| `key` | ✅ | Unique string identifier (e.g., `app_name`) |
| `platform` | ✅ | `ios`, `android`, or `android,ios` |
| `default` | ✅ | Default/fallback value |
| `en`, `my`, `zh`, etc. | Optional | Translation for each locale |

---

## How It Works

```
Google Sheets → [swift package plugin generate-ios-i18n] → Localizable.strings / .xcstrings
```

1. **Download** — Fetches CSV export from your Google Sheet (cached in `.i18n-cache/`)
2. **Parse** — Reads keys, platforms, and translations from the CSV
3. **Generate** — Writes `.lproj/Localizable.strings` or `Localizable.xcstrings` to your output directory
